# Desi Foods — sample website (pitch demo)

Single-file static site for **Desi Foods (دیسی فوڈز)**, Abdullah Centre, FB Area Block 16, Karachi
(opp. Lucky One Mall). Open `index.html` in a browser; no build needed. Deploy by dragging the
`desi-foods/` folder onto Netlify Drop or Vercel.

## Features
- Hero with the real logo, Urdu + English branding, WhatsApp / call buttons
- Signature dumba dishes, tabbed full menu, family / dawat platters
- Order cart: pick dishes, then send the whole order to WhatsApp (0300-2926900)
- Table booking form (goes to WhatsApp), Google Map, timings, gallery, reviews
- Mobile responsive, sticky nav, scroll animations
